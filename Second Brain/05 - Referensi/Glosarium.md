# Glosarium

| Istilah        | Arti dalam proyek                                                                                                     | Lokasi                    |
| -------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| Scene          | Berkas `.tscn` yang menyusun node dan properti objek/game. [[02 - Godot dan Scene/Struktur Godot]]                    | [[Struktur Godot]]        |
| GDScript       | Bahasa skrip utama untuk logika gameplay yang dibaca. [[06 - Bahasa Pemograman/GDScript]]                             | [[GDScript]]              |
| State machine  | Pola yang hanya menjalankan perilaku sesuai state aktif dan mengatur transisi. [[03 - Gameplay/State Machine Pemain]] | [[State machine pemain]]  |
| `AttackBox`    | `Area2D` yang menjadi area serangan dan diaktifkan saat frame serangan. [[03 - Gameplay/Serangan dan Fireball]]       | [[Serangan dan Fireball]] |
| Hurtbox/Hitbox | Area untuk menerima atau mendeteksi tabrakan serangan.                                                                |                           |
| Jenova         | Framework integrasi C++/runtime untuk Godot pada proyek. [[04 - Framework/Jenova]]                                    | [[Jenova]]                |
| LimboAI        | Addon Behavior Tree dan HSM; tersedia di proyek, belum tampak dipakai AI slime. [[04 - Framework/LimboAI]]            | [[LimboAI]]               |
| Respawn        | Mengembalikan karakter setelah mati. [[01 - Peta Proyek/Alur Game]]                                                   | [[Alur Game]]             |
| TileMapLayer   | Node layer tile yang digunakan sebagai tanah/dunia.                                                                   |                           |
