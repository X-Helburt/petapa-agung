# Bahasa C++

Adalah bahasa pemograman di bangun di atas bahasa c. dan memiliki header. termasuk ke dalam bahasa statis ( Static Type )

## Pengertian dan contoh

Bahasa ini menggunakan index `.cpp` dan header nya dengan index `.hpp`

```C++
 std::cout << 'hello world' << std::endl;
```
