# Bahasa GDScript

Adalah bahasa pemograman dengan syntax gabungan python dan typescript. termasuk bahasa dinamis ( Dynamic Type ). bahasa bawaan Godot Engine

## Pengertian dan Contoh
Bahasa ini menggunakan index `.gd`

```gdscript
extends CharacterBody2D
```
